## about

This project is a simple digital scrapbook created to celebrate our third month together. Instead of giving another ordinary gift, I wanted to build something that could hold our memories, little stories, photos, and moments that mean the most to us.

Every page was made with love, hoping it'll become something we can always come back to in the future.

## features

- 📖 Digital scrapbook
- 📷 Photo gallery
- 💌 Personal letters
- 🎵 Background music
- 📱 Mobile-first responsive design
- ✨ Smooth animations

## built with

- HTML
- CSS
- JavaScript
