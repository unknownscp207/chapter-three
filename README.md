# ❤️ Red String of Fate

A small corner on the internet, created to celebrate our first three months together.

This website is more than just a digital scrapbook. It is a collection of memories, letters, photographs, and little moments that remind me how something I once thought impossible slowly became the happiest part of my life.

Every section tells a different chapter of our story—from the very beginning, to the memories we've shared, the words from the people around us, and a letter written just for you.

## ✨ Features

- 🌹 Interactive welcome bouquet
- 📖 Romantic timeline
- 🖼️ Memory gallery
- 💌 Personal love letter
- 📌 Anniversary wishes from family & friends
- 🎵 Background music
- ✨ Smooth animations powered by Framer Motion
- 📱 Fully responsive design

## 🛠️ Built With

- Next.js 14
- React
- Tailwind CSS
- Framer Motion
- Lucide React

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/red-string-of-fate.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
